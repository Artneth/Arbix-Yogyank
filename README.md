# Arbix-Yogyank
Yogyank is the scoring engine behind SaakhSetu. Yogyank outputs a bank-agnostic Entitlement Score. 

## Setup & Execution
You can use this in Jupyter notebook, Google Colab or in your local enviroment.

To install xgboost, joblib, scikit-learn in any enviroment use:

`pip install pandas scikit-learn xgboost joblib`

I skipped implementing SHAP values due to time.

I assumed the rows in given dataset are sorted chronologically.
